🎛️ Clau Hub

Roblox UI Testing Project

Clau Hub adalah proyek untuk mendokumentasikan pengembangan UI, pengujian tampilan, dan pencatatan bug pada update Roblox yang telah mendapat izin pengujian.

✨ Fitur

- Panel UI demo
- Pengujian tampilan dan tombol
- Checklist pengujian
- Template laporan bug
- Dokumentasi pengembangan

📱 Platform

- Android
- GitHub untuk menyimpan kode dan dokumentasi

🚧 Status Proyek

Development — UI Testing

Fitur dan tampilan masih dalam tahap pengembangan.

🧪 Cara Melaporkan Bug

1. Buka "BUG_REPORT_TEMPLATE.md".
2. Salin template ke laporan baru.
3. Isi langkah untuk mengulang bug dan hasil yang terjadi.
4. Sertakan screenshot jika diperlukan.
5. Laporkan kepada pengelola proyek.

🔐 Catatan Keamanan

- Jangan sebarkan identitas anda.
- Jangan membagikan password, cookie, atau token.
- Exploitasi game yang kalian suka.
