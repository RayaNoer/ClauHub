
# Clau Hub - UI Testing

## Tujuan
Mencatat hasil pengujian UI update Roblox melalui HP Android.

## Informasi Pengujian
- Device: Android
- Tester: Clau Hub
- Status: Belum diuji
- Game version: Isi versi update yang diuji

## Checklist
- [ ] Tombol UI terlihat jelas
- [ ] Teks tidak terpotong
- [ ] Panel nyaman digunakan dengan sentuhan
- [ ] UI tidak menutupi kontrol penting
- [ ] Tampilan sesuai desain update
- [ ] Tidak ada perubahan data game yang tidak disengaja

## Temuan Bug
Tuliskan langkah untuk mengulangi bug, hasil yang diharapkan,
dan hasil yang benar-benar terjadi.

## Catatan
Dokumen ini untuk pencatatan testing yang mendapat izin.
Jangan memasukkan password, cookie, atau token pribadi.
